## 2. 護甲與標籤

每個單位有**近甲**、**遠甲**兩個護甲值，以及數個**標籤**（傷害加成依標籤計算）。

| 標籤 | 套用對象 |
|---|---|
| `infantry` 步兵 | 民夫、刀盾、槍戟、弓弩、丹陽兵、連弩兵、步行武將 |
| `cavalry` 騎兵 | 斥候、輕騎、重騎、弓騎、虎豹騎、騎乘武將 |
| `archer` 弓兵 | 弓兵、弩兵、弓騎、連弩兵 |
| `spear` 槍兵 | 槍兵、戟兵 |
| `siege` 攻城 | 衝車、霹靂車 |
| `building` 建築 | 所有建築 |
| `ship` 船 | 所有船 |
| `hero` 武將 | 所有武將 |
| `strategist` 謀士 | 謀士 |

## 3. 傷害公式

```
傷害 = max(1, 攻擊 − 對應護甲 + Σ 標籤加成) × 高低差修正 × 狀態修正
```

| 項目 | 規則 |
|---|---|
| 對應護甲 | 近戰攻擊看近甲，遠程攻擊看遠甲 |
| 高低差修正 | 高打低 ×1.25（蜀 ×1.4）；低打高 ×0.75；同高 ×1 |
| 狀態修正 | 武將光環、計策、科技等加總後相乘 |
| 遠程命中 | 對靜止目標 100%；對移動目標 80%（以種子亂數判定，保持確定性）；未命中的箭落地，不誤傷 |
| 火焰 | 每秒傷害、**無視護甲**；對建築、船 ×2；吳 ＋25% |
| 範圍傷害 | 霹靂車、火船：中心 100%，邊緣 50%，會傷到己方 |
| 最低傷害 | 至少 1（再硬的單位也能被磨死） |

## 4. 戰鬥行為

| 行為 | 規則 |
|---|---|
| 攻擊冷卻 | 每個兵種有固定冷卻時間（`06 §4`） |
| 自動索敵 | 在視野內找目標；優先順序：正在打我的 → 軍事單位 → 民夫 → 建築 |
| 姿態 | 進攻（追擊）／防守（追擊 8 格後返回，預設）／堅守（不移動）／不還擊 |
| 攻擊移動 | 沿路遇敵就打，打完繼續前進 |
| 巡邏、跟隨、守衛 | 標準 RTS 行為 |
| 民夫受攻擊 | 自動逃往最近的太守府或關隘 |
| 自動拉打 | 遠程單位保持在射程邊緣（玩家可開關；困難 AI 預設開） |
| 駐軍 | 太守府、關隘、箭塔可駐軍，每多 N 人多射一支箭（`06 §6`） |
| 隊形移動 | 選取多單位移動時，以最慢單位的速度前進，抵達後整隊 |

### 陣型

| 陣型 | 排列 | 用途 |
|---|---|---|
| 方陣（預設） | 近戰在前、遠程在後、攻城和謀士在最後 | 一般會戰 |
| 錐形 | 騎兵在尖端 | 突破 |
| 散開 | 單位間距 ×2 | 防霹靂車和火攻 |

## 5. 兵種一覽與外觀剪影

Q 版比例下，兵器放大 1.5 倍，**從最遠鏡頭靠剪影就能分辨兵種**。

| 兵種 | 時代 | 產地 | 剪影重點 |
|---|---|---|---|
| 民夫 | I | 太守府 | 斗笠、短褐；手上工具依工作切換（斧、鋤、鎬、槌） |
| 斥候騎 | I | 開局贈送 | 小馬、輕裝、背小旗 |
| 刀盾兵 | I | 兵營 | 環首刀 ＋ 大圓盾 |
| 槍兵 → 戟兵 | II → III | 兵營 | 長槍超過身高 2 倍（最好認）；戟頭有月牙 |
| 弓兵 → 弩兵 | II → III | 弓營 | 長弓、背箭筒／橫握弩 |
| 輕騎 → 驍騎 | II → III | 馬廄 | 輕裝小馬、紅纓 |
| 重騎 → 鐵騎 | III → IV | 馬廄 | 馬披甲、騎士戴兜鍪 |
| 弓騎 | III | 弓營 | 騎馬持弓 |
| 謀士 | III | 書院 | 羽扇、儒冠、寬袖長袍 |
| 衝車 | III | 工坊 | 木屋頂 ＋ 撞木 |
| 霹靂車 | IV | 工坊 | 配重投石機，需架設 |
| 漁船／運兵船 | I／II | 船塢 | 小舢舨／平底寬船 |
| 走舸／艨艟／樓船 | II／III／IV | 船塢 | 小快船／包皮衝角船／三層樓船 |
| 虎豹騎（魏） | III | 關隘 | 黑甲、虎紋馬鎧 |
| 連弩兵（蜀） | III | 關隘 | 方盒狀連弩 |
| 丹陽兵（吳） | III | 關隘 | 重甲、方盾、短戟 |

## 6. 水戰與地形

| 規則 | 內容 |
|---|---|
| 深水 | 只有船能進入 |
| 淺灘 | 步兵、騎兵可涉水，移速 −30%；船不能進入 |
| 運兵船 | 載 8 個人口；靠岸點擊地面即卸載 |
| 魚群 | 漁船採集，見 `06 §2` |
| 森林 | 擋路，不擋視線 |
| 高地 | 視野 ＋2，攻擊修正見 §3 |
| 火勢延燒 | 森林和相鄰建築會被點燃（每秒 25% 機率延燒到相鄰格，種子亂數） |

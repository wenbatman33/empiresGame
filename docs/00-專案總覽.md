## 1. 產品北極星

| 項目 | 定義 |
|---|---|
| 一句話定位 | 三國題材的 Q 版 3D 即時戰略：從黃巾亂世的一座太守府起家，採集、築城、升時代，帶著關羽、趙雲、諸葛亮逐鹿天下 |
| 致敬對象 | 世紀帝國 II（經濟 ＋ 升時代 ＋ 兵種相剋）＋ 魔獸爭霸 III（英雄技能）＋ 三國演義名場面（赤壁火攻、長坂怒吼、七進七出） |
| 核心體驗 | 15–25 分鐘一局：前 5 分鐘經營擴張的爽感 → 中期升時代軍備競賽 → 後期武將技決戰 |
| 平台 | Web：PC 瀏覽器 ＋ 手機瀏覽器（橫向，可安裝成 PWA），同一份程式 |
| 模式 | Phase 1 單機：自由對戰 AI、戰役；Phase 2：多人連線 |
| 商業模型 | **[待確認]** 預設不做付費 |
| 成功公式 | 3 分鐘內讓第一個民夫開始採集 ＋ 第一局 20 分鐘內打完 ＋ 第一次放出武將技時的「哇」 |

## 2. 設計支柱

| # | 支柱 | 具體規則 |
|---|---|---|
| 1 | **經典 RTS 骨架不打折** | 採集 → 建造 → 升時代 → 相剋戰鬥。玩過世紀帝國的人 30 秒上手 |
| 2 | **三國味來自「人」** | 武將是戰場焦點；每位武將的技能都對應一段演義名場面，放技能時有特寫 |
| 3 | **手機是一等公民** | 所有操作都能只用觸控完成；重複性操作（回倉、重播農田、集結）自動化 |
| 4 | **一眼看懂戰場** | Q 版大頭比例 ＋ 隊伍色 ＋ 放大的兵器剪影，最遠的鏡頭也分得出槍兵、弓兵、騎兵 |
| 5 | **短局高密度** | 一局 15–25 分鐘，時代節奏壓縮，但保留升時代的儀式感 |

## 3. 已定案決策（2026-10-01）

| 決策 | 選擇 | 影響 |
|---|---|---|
| 技術平台 | Web ＋ Three.js ＋ Vite ＋ TypeScript | 和 happyFarm 同一套；PC 與手機共用同一份程式 |
| 美術風格 | **Q 版低多邊形** | 頭身比 1:2、平塗色塊；建築、地形、樹用程式建模，兵種和武將用 Blender 腳本建模 |
| 連線範圍 | **先單機對 AI，預留多人** | 模擬層從第一天就做成確定性（固定 tick、定點數、種子亂數、指令佇列），之後加 lockstep 多人不用重寫 |
| 對局規模 | **手機友善短局 15–25 分** | 預設中小地圖、人口上限 125、升時代較快；大地圖、200 人口留在開局設定 |
| 部署 | GitHub `wenbatman33/empiresGame` → GitHub Pages | 推到 `main` 由 Actions 自動部署；網址加 `?dev=1` 開 DEV 工具；**每次推版前先問使用者** |

## 6. 原創性與授權

- 不使用「Age of Empires／世紀帝國」的名稱、圖示、音效（微軟商標）。
- 三國歷史與演義人物屬公有領域，但**不參考**光榮（KOEI）《三國志》《真・三國無雙》的角色造型與立繪，武將外觀一律自行設計。
- 字型用 OFL 授權（霞鶩文楷 TC）；音效用自製或 CC0；AI 生圖由 Codex 內建 image_gen 產生。

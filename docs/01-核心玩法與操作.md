# 01 — 核心玩法與操作

---

## 1. 三層遊戲迴圈

| 層 | 時間尺度 | 玩家在做什麼 | 回饋 |
|---|---|---|---|
| 指令 | 秒 | 選取 → 下指令 | 點擊波紋、單位語音（「得令！」「末將領命！」）、單位立刻轉身 |
| 經營 | 分 | 分配民夫 → 蓋建築 → 訓練部隊 → 研究科技 | 資源數字跳動、建築長高、部隊集結 |
| 一局 | 15–25 分 | 四時代推進 → 兩到三波大戰 → 勝負 | 升時代全螢幕演出、武將特寫、勝利結算 |

## 2. 一局的標準流程（1v1、中原地圖、標準起始）

| 時間 | 時代 | 玩家在做什麼 |

| 0:00–1:30 | 黃巾亂世 | 太守府連續生民夫、蓋民居、採野果；斥候騎探路找獵物 |

## 3. 勝利條件

| 條件 | 規則 | 預設 |
|---|---|---|
| 征服 | 敵方**失去所有太守府、關隘，且沒有民夫** → 判負（不用追殺最後一間民居，手機友善） | 開 |
| 奇觀 | 奇觀建成後存活 300 秒 | 開 |
| 稱帝 | 持有「傳國玉璽」並放在自己的書院 300 秒 | 開 |
| 斬將 | 每方有一名主公（劉備／曹操／孫權），主公陣亡即敗 | 關 |
| 投降 | 隨時可投降 | — |

**開局設定**：地圖類型、地圖大小、對手數與難度、勢力（可隨機）、起始時代（I／II／III）、起始資源（標準／充足／豐厚）、人口上限（75／125／200）、遊戲速度（0.75／1.0／1.5）、勝利條件、揭露地圖。

## 4. PC 操作

| 動作 | 操作 |
|---|---|
| 選取 | 左鍵點選；左鍵拖曳框選；雙擊＝畫面內同類；Shift＋點選＝加選／減選 |
| 編隊 | Ctrl＋數字＝設定；數字＝選取；連按兩次＝鏡頭跳過去 |
| 智慧指令 | 右鍵：依目標自動判斷移動／攻擊／採集／建造／修理／駐軍 |
| 攻擊移動 | A ＋ 左鍵（路上遇敵就打） |
| 排隊指令 | Shift ＋ 右鍵 |
| 鏡頭 | WASD／方向鍵／滑鼠碰邊緣 平移；滾輪 縮放；中鍵拖曳 旋轉 ±45°（放開回彈，可關） |
| 快速跳轉 | 空白鍵＝最近事件；H＝太守府；`.`＝閒置民夫；`,`＝閒置軍隊；F1–F3＝武將 |
| 指令卡 | 5×3 格，快捷鍵對應 Q W E R T ／ A S D F G ／ Z X C V B |
| 其他 | B＝建造選單；Esc＝取消／選單；P＝暫停（單機） |

## 5. 手機操作（強制橫向）

| 動作 | 操作 |
|---|---|
| 點選 | 單指點：單位觸控判定半徑放大到 24px；單位與建築重疊時優先選單位 |
| 框選 | 長按 0.3 秒後拖曳＝框選；或按左側「框選」切換鈕後單指拖曳 |
| 智慧指令 | 已選取時點地面／敵人／資源／建築 → 自動判斷（等同 PC 右鍵） |
| 平移 | 單指拖曳；點小地圖跳轉 |
| 縮放／旋轉 | 雙指捏合縮放；雙指旋轉（預設關） |
| 選同類 | 雙擊單位 |
| 編隊 | 右側 1–5 編隊鈕：長按＝設定、點＝選取、雙擊＝鏡頭跳過去 |
| 武將技 | 選到武將時右下出現大圓鈕（MOBA 式）；點一下＝原地施放，拖曳＝指定方向或範圍 |
| 建造放置 | 兩段式：拖曳預覽位置 → 點 ✔ 確認，避免誤蓋 |
| 誤觸防護 | 拆除、投降、刪除佇列需二次確認 |

直向畫面顯示「請轉為橫向」提示（RTS 直向無法好好玩）。

## 6. 減少操作量的自動化

PC 和手機都有，手機預設全開。

| 功能 | 行為 |
|---|---|
| 自動回倉 | 民夫採滿自動送到最近的存放點，再回頭繼續採 |
| 存放點自動開工 | 蓋好伐木場／礦場後，參與建造的民夫自動採附近資源 |
| 農田自動重播 | 農田耗盡且木材足夠時自動重播（可關） |
| 集結點 | 設在資源上 → 新民夫自動去採；設在地面 → 集合待命 |
| 循環生產 | 生產佇列可設為「循環」，有資源就一直生 |
| 閒置提示 | 閒置民夫鈕顯示人數並閃爍 |
| 民夫被攻擊 | 自動逃回太守府；「警鐘」一鍵讓附近民夫全部入府放箭 |
| 自動反擊 | 單位被打會自動還手；遠程單位可開「自動拉打」（保持距離射擊） |
| 民夫分配助手 | **[待確認・M4]** 設定糧／木／金／石的目標比例，閒置民夫自動補位 |

## 7. 鏡頭

| 參數 | 預設 | 說明 |
|---|---|---|
| 投影 | 透視 | 偏長焦（FOV 40°），接近世紀帝國的等角視感，又保留 3D 立體感 |
| 俯角 | 55° | DEV 工具可調 |
| 高度 | 18–60 | 手機預設比 PC 近一級，單位才夠大、好點 |
| 旋轉 | 預設不轉 | PC 中鍵 ±45° 回彈；手機雙指旋轉預設關 |
| 邊界 | 地圖外最多露出 10% | 避免看到世界盡頭 |

## 9. 回饋與手感

| 情境 | 回饋 |
|---|---|
| 下指令 | 地面波紋標記 ＋ 單位語音 ＋ 選取音 |
| 受擊 | 白閃 0.08 秒、輕微擊退、血條抖動；不見血，改冒小星星（Q 版、分級友善） |
| 死亡 | 倒地 ＋ 淡出，留下兵器 10 秒 |
| 建造 | 鷹架依進度逐步長高；完工揚起煙塵 ＋ 鑼聲 |
| 建築被毀 | 崩塌 ＋ 火焰 ＋ 殘骸 30 秒 |
| 升時代 | 卷軸展開書法大字「群雄割據」＋ 戰鼓；所有建築外觀換成下一個時代 |
| 武將技 | 0.6 秒武將特寫（立繪 ＋ 技能名書法字）→ 技能特效 → 鏡頭輕震 |

特寫期間遊戲時間**不暫停**（多人時才公平）；單機可在設定開「特寫慢動作」。

## 10. 新手引導

- 第一次進遊戲推薦「戰役 1-1 桃園結義」（教學關，見 `08 §1`）：移動 → 採集 → 蓋民居 → 生民夫 → 蓋兵營 → 戰鬥。
- 自由對戰有「軍師提示」：閒置民夫、人口卡住、資源囤太多時跳出建議（可關）。
- 指令卡長按（手機）或懸停（PC）顯示說明，兵種按鈕會寫「剋：騎兵／怕：弓兵」。

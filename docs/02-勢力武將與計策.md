## 3. 武將系統

### 3.1 規則

| 規則 | 內容 |
|---|---|
| 訓練 | 在關隘訓練（三分天下起） |
| 在場上限 | 三分天下 1 名、天下一統 2 名 |
| 技能 | 每位 1 個主動技 ＋ 1 個被動 |
| 陣亡 | 原地留下「將旗」；可在關隘半價復活，冷卻 90 秒 |
| 威名 | 擊殺累積威名 → Lv1 到 Lv3，每級 HP 和攻擊 ＋10%；上限 Lv3，避免滾雪球 |
| 抗性 | 不能被勸降；恐懼、緩速等控制效果時間減半 |
| 施放 | 特寫 cut-in 0.6 秒，期間遊戲不暫停 |

## 6. 平衡原則

1. 每個勢力在某個時代要有明顯的強勢窗口（見 §1），對手要能預期並準備。
2. 吳在純陸地圖不能太弱：用丹陽兵、火攻、射程補強。
3. 武將強但不能單挑整支軍隊：一名滿級武將約等於 8–10 名同時代主力兵的戰力。
4. 用 AI 對 AI 無頭模擬（`05 §8`）各勢力跑 100 局，目標勝率 45–55%。

## 3. 程式產生地圖

全部用**種子**產生，同一個種子永遠產生同一張地圖（多人連線和重播都靠這點）。

```
1. 種子 → 高度場（多層雜訊 ＋ 地圖類型模板）
2. 水體：依模板挖河、湖、海；標記深水與淺灘
3. 玩家起始點：依人數對稱放置，彼此距離相等
4. 每位玩家的起始資源（§4），用「同一套相對位置 ＋ 微幅亂數」保證公平
5. 中立資源：中央額外金礦、石礦、兵書、玉璽
6. 森林：雜訊填充，確保每個起始點附近有一片大森林
7. 裝飾：岩石、花草、遺跡（純視覺）
8. 驗證：每個玩家都走得到彼此（除了水圖）、資源數量誤差 < 5%；失敗就換子種子重來
```

## 6. 電腦 AI 架構

**原則：AI 只透過「指令 API」下指令**，和玩家、未來的網路玩家走同一條路。AI 不直接改遊戲狀態（只有「瘋狂」難度會額外加資源）。

```
                ┌──────── 情報：依自己的視野記錄敵方建築與軍隊估計
                │
戰略層（每秒）──┼──────── 經濟經理：目標民夫數、分配比例、蓋存放點／農田／民居
                ├──────── 建造經理：依勢力的建造順序 JSON，之後轉成條件規則
                ├──────── 研究經理：科技優先順序表
                └──────── 軍事經理：兵種組成、集結、進攻／防守／撤退判斷
戰術層（每 0.5 秒）────── 集火低血目標、遠程拉打、武將技時機、殘血武將撤退
```

| 模組 | 重點 |
|---|---|
| 經濟 | 各時代目標民夫數 20／35／55／70；人口差 ≤ 5 就蓋民居；存放點離資源 > 12 格就蓋新的 |
| 建造順序 | `src/data/ai/build_orders/<勢力>_<風格>.json`，風格：速攻、穩健、快升時代 |
| 兵種組成 | 依「觀察到的敵方組成」查相剋表，自動補反制兵種 |
| 進攻時機 | 以「軍隊戰力值」（HP × 攻擊 × 相剋係數的總和）比較；我方 ≥ 敵方估計 × 1.3 才進攻 |
| 防守 | 太守府半徑 20 內出現敵軍 → 召回軍隊，民夫入府 |
| 武將技 | 範圍內敵人數 ≥ 閾值（例如 6）或武將 HP < 40% 時施放 |
| 決策方式 | 效用評分（Utility AI）：每個候選行動算分數，取最高；參數全部資料化 |

## 7. 難度

| 難度 | 採集倍率 | 思考間隔 | 各時代目標民夫（I／II／III／IV） | 出擊兵力門檻（II／III／IV） | 第一波最早 | 波數 |
|---|---|---|---|---|---|---|
| 簡單 | ×0.8 | 3 秒 | 14／24／34／42 | 10／14／18 | 14:00 | 最多 2 波 |
| 普通 | ×1.0 | 1.5 秒 | 15／27／44／56 | 10／16／22 | 8:00 | 不限 |
| 困難 | ×1.0 | 0.5 秒 | 16／28／50／62 | 14／22／30 | 9:00 | 不限 |
| 瘋狂 | ×1.3 | 0.3 秒 | 同困難 ＋ 全圖視野 | 14／22／30 | 8:00 | 不限 |

簡單到困難都**不作弊**（只看自己的視野、只透過指令操作），只有瘋狂會作弊，並在選單標明。

**AI 行為（M3 實作）**：

- 經濟：標準建造順序機器人；各時代採集比例不同，並依庫存動態調整（囤太多的少採、見底的多採）；天然糧食只採存放點 9 格內的，其餘蓋農田；資源採遠了就在新地點加蓋伐木場／礦場。
- 升時代：民夫到門檻後存錢（停生民夫），家裡被攻擊時不存錢先防守。
- 軍隊：依時代基本組合 ＋ 依看到的敵軍反制（敵騎多 → 槍、敵弓多 → 騎、敵步多 → 弓）；三分天下起造衝車、天下一統起造霹靂車。
- 出擊：第一波照時間與最低兵力（偏騷擾）；之後兵力要比看到的敵軍多三成才出擊；剩不到三成就撤退。衝車專打太守府，其他兵攻擊移動、遇敵就打。找不到敵方建築時分區掃蕩地圖。
- 個性：依種子決定進攻時機（−90～＋120 秒）、兵力門檻（±4）、偏好兵種，AI 對 AI 不會完全對稱。
- 投降：失去太守府且民夫 < 15、或軍隊與民夫都所剩無幾，持續 30 秒就投降。

**AI 行為（M4 新增）**：

- 勢力：三分天下、民夫 ≥ 34 時蓋關隘（還沒存夠 650 石就多派人採石），之後生勢力特殊兵種與本勢力武將；關隘蓋好、兵力 ≥ 12 才蓋書院。
- 武將技：武將 7 格內敵軍 ≥ 5 時對敵軍中心施放；夏侯惇、司馬懿血量 < 40% 時自保施放；陸遜只對附近有敵方建築時施放。
- 計策：進攻中、金 ≥ 500 時，對看得到的敵軍最密集處（4×4 格內 ≥ 8 人）放火攻計。
- 水圖（長江、赤壁）：民夫 ≥ 9 時在最近的岸邊蓋船塢、最多 6 艘漁船自動捕魚；兵種組合加入走舸、艨艟（吳再加火船）。
- 三分天下還沒工坊時先存木頭蓋工坊（攻城器械優先，避免消耗戰拖長）。
- 三國特色科技（書院、關隘、市集、船塢）要兵力 ≥ 18 才研究。

**地圖實作（M4）**：四種地圖都由同一個產生器依類型參數產生，整張地形（高度、河道／山脊、渡口／隘口、森林、岩塊）都**對地圖中心點對稱**，兩邊完全公平（原本森林用雜訊隨機分布，AI 對戰發現某一方出生點附近森林多三倍、經濟系統性佔優，改成鏡像）：

| 地圖 | 實作 |
|---|---|
| 中原 | 斜貫細河、3 處淺灘 |
| 長江 | 河寬約 1.9 倍、3 處淺灘、每方約 3–4 處魚群 |
| 蜀道 | 中央山崖（不可通行、高起）＋ 3 個隘口（兩側 ＋ 中央放玉璽的窄口）、零散岩塊、地形起伏大 |
| 赤壁 | 整片江面、只有兩端角落有陸橋（陸路要繞遠）、江心小島放玉璽（要用運兵船）、每方 6 處魚群 |

起始資源驗證：動物與野果不放在森林格；被森林或山崖包住的資源會沿直線往出生點開路，保證走得到。

## 8. 無頭 AI 對戰（平衡與回歸測試）

模擬層和渲染層分開（`07 §3`），所以可以在 Node 裡不開畫面直接跑整局：

```bash
npm run ai-arena -- --games 100 --map central --a wei:hard --b shu:hard
```

輸出：勝率、平均對局時間、各時代到達時間、各兵種產量與擊殺。用途：

1. **平衡**：勢力勝率目標 45–55%（`02 §6`）、相剋測試（`09` M2 驗收）。
2. **節奏**：驗證一局 15–25 分鐘、時代到達時間符合 `06 §3`。
3. **回歸**：每次改數值或 AI 後跑一輪，確認沒有退化；也順便驗證確定性（同種子跑兩次結果一致）。

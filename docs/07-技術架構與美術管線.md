## 1. 技術棧

| 層 | 選擇 | 理由 |
|---|---|---|
| 建置 | Vite ＋ TypeScript | 和 happyFarm 同一套；資料表多的遊戲特別需要型別 |
| 3D | Three.js（WebGL2） | 已定案；WebGPU 渲染器等手機支援成熟再評估 |
| 模擬層 | 自寫確定性 ECS（TypedArray 結構陣列） | 可在主執行緒或 Web Worker 跑；也能在 Node 無頭跑 |
| 數學 | 模擬層用**定點數**（1 格 ＝ 256）、角度用整數查表 | 跨裝置結果完全一致，多人 lockstep 的前提 |
| 尋路 | 自寫：格網 A*（JPS）＋ Flow Field ＋ 分層 HPA* | RTS 尋路要針對大量單位客製 |
| UI | Preact ＋ CSS，HTML 疊在 canvas 上 | 文字清晰、響應式好做、DEV 工具好拖曳 |
| 後製 | pmndrs `postprocessing`（只在高畫質開） | FXAA／SMAA、輕 Bloom、N8AO |
| 模型 | glTF ＋ Meshopt；VAT 資料 `.bin` | 手機下載量與記憶體 |
| 音效 | Howler.js | 手機音訊解鎖、音效池 |
| 存檔 | IndexedDB（idb-keyval） | 存檔與重播 |
| PWA | vite-plugin-pwa | 離線、加到主畫面 |
| DEV 工具 | lil-gui ＋ 自寫拖曳覆蓋層 ＋ TransformControls | 見 §9 |
| 測試 | Vitest | 模擬層單元測試、確定性雜湊測試；`scripts/check-sim.mjs` 檢查模擬層禁用 API |
| 部署 | GitHub Actions → GitHub Pages | https://wenbatman33.github.io/empiresGame/ |

## 3. 模擬層與渲染層分離（最重要的架構決策）

```
玩家輸入 ─┐
電腦 AI  ─┼─→ 指令佇列 Command { tick, playerId, type, unitIds, target }
網路(P2) ─┘          │
                     ▼  每 tick（100ms）依序執行
            模擬層 sim.step()  ── 世界狀態（定點數、TypedArray）
                     │
                     ▼  每 tick 產生快照（位置、朝向、動畫狀態、HP）
            渲染層 render(alpha) ── 在前後兩個快照之間內插 → 60fps 畫面
```

### 確定性規則（`scripts/check-sim.mjs` 強制檢查，建置前自動執行）

1. `src/sim/` 不得 import `three`、DOM、`ui/`、`render/`。
2. 模擬層禁用 `Math.random`、`Date.now`、`performance.now`、`Math.sin/cos/atan2/pow/exp`；改用種子亂數（xoshiro128**）與整數查表。
3. 位置、速度、HP 用整數或定點數；除法統一用整數除法函式。
4. 遍歷實體一律依 id 排序；不依賴物件屬性順序以外的雜湊順序。
5. 每 tick 計算狀態雜湊。測試：同種子 ＋ 同指令跑兩次，雜湊必須一致。

### 這個架構帶來的好處

| 好處 | 說明 |
|---|---|
| 重播 | 重播檔 ＝ 種子 ＋ 指令紀錄，只有幾 KB，可快轉 |
| 多人 | lockstep 只傳指令，見 `08 §3` |
| 無頭測試 | 在 Node 跑整局 AI 對戰做平衡（`05 §8`） |
| 手機效能 | 模擬層可整個搬進 Web Worker，主執行緒只負責渲染（M0 實測決定） |
| 除錯 | 出 bug 時存下重播，就能 100% 重現 |

### 操作手感

指令實際在**下一個 tick** 生效（單機最多 100ms 延遲），但 UI 回饋（點擊波紋、語音、單位轉身）立刻在渲染層播放，玩家感覺不到延遲。

## 4. 尋路與移動

| 情境 | 演算法 |
|---|---|
| 格網 | 每格一個通行位元遮罩：陸地／淺灘／深水／建築／森林／懸崖；建築蓋好或被毀時局部更新 |
| 單一單位或小隊（< 8） | A*（JPS 加速）＋ 路徑平滑（拉直線） |
| 大隊（≥ 8）同一目的地 | **Flow Field**：以目的地為源算整合場與方向場，全隊共用；有快取、可分幀計算 |
| 長距離 | 分層 HPA*（16×16 區塊）：先找區塊路徑再細算（M2 視效能決定是否需要） |
| 局部避碰 | 空間雜湊（2×2 格一桶）＋ 分離力 ＋ 推開閒置友軍；卡兵嚴重再升級為 ORCA |
| 陣型 | 目標點依陣型偏移分配給每個單位（`03 §4`） |
| 採集與建造站位 | 資源或建築周圍可站的格子做「槽位」分配，避免民夫擠成一團 |

DEV 工具可以疊加顯示：通行格網、Flow Field 箭頭、單位路徑、空間雜湊桶。

## 5. 渲染

| 項目 | 做法 |
|---|---|
| 地形 | 高度圖切成 32×32 格的區塊（視錐剔除）；頂點色 ＋ 混合層（草／土／沙／岩／農田）；平面法線做出低多邊形感 |
| 水 | 平面 ＋ 簡易 shader：深淺漸層、岸邊泡沫、法線擾動；低畫質改靜態 |
| 兵種 | 每種「兵種 × 外觀」一個 `InstancedMesh`；**VAT（頂點動畫貼圖）**：把每個動畫每一格的頂點位置烘成貼圖，vertex shader 依實例屬性（動畫 id、起始時間、播放速度）取樣。一個兵種一次 draw call 畫完所有單位 |
| 隊伍色 | 頂點色的一個通道當遮罩，乘上實例顏色（旗幟、肩甲、頭巾、屋簷飾帶） |
| 武將 | 數量少（≤ 16），用一般 `SkinnedMesh` ＋ `AnimationMixer`，模型精度較高、加描邊 |
| 建築 | 依「類型 × 時代 × 勢力」合併幾何後實例化；施工中用裁切平面 ＋ 鷹架模型 |
| 樹與資源 | `InstancedMesh` ＋ 風吹搖擺 vertex shader；砍倒換成樹樁 |
| 選取圈、血條、標記 | 實例化的平面和 billboard，不用 DOM |
| 投射物 | 箭、石、火球用物件池 ＋ 實例化 |
| 特效 | GPU 實例化粒子：塵土、火、煙、火花、受擊星星 |
| 光照 | 一盞方向光（投影）＋ 半球光；`MeshLambertMaterial` ／ Toon 漸層，Q 版柔和感 |
| 陰影 | 陰影相機緊貼可視範圍；PC 2048、手機 1024、低畫質改成圓形假陰影 |
| 畫質分級 | 第一次啟動跑 2 秒基準測試自動選低／中／高，設定頁可改 |
| 點選判定 | **不用** Three.js 射線打實例網格。射線只打地形取得世界座標，再查模擬層空間雜湊；框選則把單位投影到螢幕座標比對矩形 |

## 6. 效能預算

| 項目 | 手機（2021 年後中階機） | PC |
|---|---|---|
| 幀率 | 穩定 30fps（能 60 更好） | 60fps |
| 同時在場單位 | 300 | 800 |
| Draw calls | ≤ 100 | ≤ 300 |
| 三角形 | ≤ 30 萬 | ≤ 150 萬 |
| 單一模型三角形 | 兵 300–600、武將 2–3k、建築 500–3k | 同左 |
| 解析度倍率（DPR） | 上限 1.5（低畫質 1.0） | 上限 2.0 |
| 模擬一個 tick | ≤ 6 ms | ≤ 3 ms |
| 首次下載 | ≤ 15 MB（之後由 PWA 快取） | 同左 |
| 記憶體 | ≤ 400 MB（iOS Safari 的限制） | — |

**降級順序**（手機不達標時）：陰影 → 圓形假陰影、DPR 1.0、關後製、樹木密度減半、人口上限 75、模擬移到 Worker。

### 8.1 風格指南

| 規則 | 內容 |
|---|---|
| 比例 | Q 版頭身比 1:2；武將 1:2.3、體型 1.3 倍 |
| 造型 | 低多邊形、平塗色塊、不用寫實貼圖 |

| 隊伍色 | 旗幟、肩甲、頭巾、屋簷飾帶 |
| 暴力表現 | 不見血；受擊白閃 ＋ 星星，死亡倒地淡出 |
| 建築 | 漢代建築語彙，四時代外觀演進（`04 §3`） |

| 背景音樂 | 約 8 首 | ⚠️ **需外部**：AI 音樂服務（使用者帳號）或 CC0 古風曲 | — |

### 8.3 兵種模型的分段策略

1. **M0–M4：程式建模的佔位 Q 版兵**。在瀏覽器裡用部件組合（頭、身、四肢、兵器、坐騎），載入時把程式動畫**當場烘成 VAT**。這樣不必等 Blender，就能先驗證 VAT 渲染路徑與效能。
2. **M5：換成 Blender 正式模型**。用同一個 VAT 資料格式，渲染程式完全不用改。

### 8.4 AI 生圖批次

照全域準則走 `codex exec` 內建 image_gen，不需要 API key：

1. `scripts/asset_manifest.json`：每項 `{ id, cat, prompt, size, out }`。
2. prompt 統一前綴鎖定風格：「Q 版三國、低多邊形 3D 渲染風、柔和光、平塗色塊、32 色調色盤、單一主體、純色背景」。
3. `scripts/gen_via_codex.mjs` 逐項呼叫，`existsSync` 跳過已存在的檔案，可中斷續跑；在背景執行。
4. 後處理：`sips` 縮到目標尺寸、去背、壓成 WebP。

## 10. 存檔、重播與部署

| 項目 | 做法 |
|---|---|
| 存檔 | 模擬狀態序列化（定點數 → 無損）；單機每 60 秒自動存檔 |
| 重播 | 種子 ＋ 指令紀錄；可快轉、跳時間點 |
| 版本 | 存檔帶版本號，資料表改版時做遷移 |
| 部署 | 推到 `main` → GitHub Actions 建置 → GitHub Pages；`vite.config.ts` 用 `base: './'` |
| 線上網址 | https://wenbatman33.github.io/empiresGame/（加 `?dev=1` 開 DEV 工具） |
